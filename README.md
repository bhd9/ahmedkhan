# The Living Agilist

A clean, modern static website about Agile practices, transformation, and continuous improvement.

## About

This is a GitHub-hosted static website featuring insights, stories, and reflections from nearly two decades of Agile practice and coaching.

## Features

- **Responsive Design**: Works beautifully on desktop, tablet, and mobile
- **Modern UI**: Clean typography and professional styling
- **Blog Section**: Articles and stories about Agile journey
- **Resources Page**: Curated Agile resources, tools, and reading recommendations
- **Contact Form**: Easy way to get in touch

## Structure

- `index.html` - Homepage with featured content
- `blog.html` - Blog listing page
- `blog/` - Individual blog post pages
- `about.html` - About page
- `resources.html` - Agile resources and recommendations
- `contact.html` - Contact form and newsletter signup
- `styles.css` - All styling and responsive design

## Deployment

This site is designed to be hosted on GitHub Pages. Simply push to your repository and enable GitHub Pages in the repository settings.

## Customization

To customize the site:
1. Edit the HTML files for content changes
2. Modify `styles.css` for styling updates
3. Update colors in the CSS `:root` variables for brand consistency
